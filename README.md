# Pokédex

Aplicación web desarrollada con Angular que consume la [PokéAPI](https://pokeapi.co/) para mostrar información de Pokémon.

## Funcionalidades

- **Dashboard**: muestra 9 Pokémon aleatorios en cada recarga y un buscador por nombre
- **Listado**: tabla paginada con ID y nombre (20 Pokémon por página)
- **Detalle**: información completa al hacer clic en un Pokémon (nombre, imagen, ID, tipos, altura, peso y estadísticas)

## Cómo ejecutarlo

```bash
npm install
ng serve
```

Abre `http://localhost:4200` en el navegador.
